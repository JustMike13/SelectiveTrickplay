Unwatched Trickplay Configuration

About This Plugin

This plugin automatically generates trickplay (preview) thumbnails for movies and episodes that are unwatched by at least one of your selected users.

Scheduled to run daily at 03:00 AM

Select Users

Choose which users' watch status should be checked. Trickplay will be generated for content that is unwatched by any of these users.

Information

  • Trickplay files are generated only if they don't already exist
  • Only movies and episodes are processed
  • Content watched by ALL selected users is skipped
